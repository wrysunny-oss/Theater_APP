# 组件目录约定

- `common/`：无业务含义的基础组件，例如页面头部、页面状态和表单字段。
- `home/`：首页剧场组件，例如轮播、筛选、榜单和短剧网格。
- `library/`：用户内容库组件，目前包含观看历史项和收藏卡片。
- `player/`：沉浸式播放器组件，目前包含操作浮层和选集面板。
- `tasks/`、`earnings/`、`user/`：对应业务模块的专用组件。

页面文件只负责路由参数、数据加载和业务状态编排。可复用展示结构放入对应业务组件目录；跨业务且不包含领域语义的组件放入 `common/`。

响应式业务状态不要写进展示组件，统一放入 `src/composables`；数据读取和写入继续由 `src/services` 负责。
